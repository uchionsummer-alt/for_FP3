# 公開過去問の分析と再構成の編集補助

通常のビルドはdata/chapter-XX.js、data/reviews.json、data/past-exam-analysis.json、data/unit-revision-notes.jsonだけを読みます。ネットワークや制作時の/tmpキャッシュは不要です。

catalog.pyは日本FP協会の2024〜2026年5月公表分の学科180問・実技60問を読んだ分類メモです。原問・模範解答の番号、URL、原問の法令基準日、PDFのハッシュを記録します。公表年を実施年とみなしたり、年1セットを非公開CBT全体の頻度に換算したりしません。問題本文の代わりに独自要約を保存しています。

chapter-XX.cjsは照合済みの制作原稿です。第1章の差替えを先に制作・ブラウザーで確認し、その後に第2〜6章・実技を制作しました。各原稿のfinishは、レビュー結果を生成データへ反映する書込み操作なので、本文の読解と施行日・正解・計算・誤答肢の確認なしに一括実行しないでください。HTTP取得や抜粋文字列の一致だけで、意味の正しさや法令適用を保証するものではありません。

制作時のauthor.cjsは/tmp/fp3-review-2026の本文・取得記録、/tmp/fp3-pastのPDFテキストを使いました。キャッシュ別名とURLはdocs/review-source-index.json、採用した根拠はdocs/source-audit.jsonと各問reviews.jsonに保存しています。画像の表は目視で転記し、抽出方法を記録しました。再取得で内容や施行範囲が変わったら再読解が必要であり、古いハッシュへ機械的に合わせません。

本文・資料表・過去問対応・版・計算メモ等を変更した場合、ダイジェスト不一致でビルドが停止します。通常は生成済み原稿を直接編集し、根拠を再確認してreviews.jsonを更新します。確認できないものはpendingとして保持し、通常テストから除外します。

原問の利用条件： https://www.jafp.or.jp/exam/mohan/files/exam_riyou.pdf
出典と修正・加工を各問に表示し、原本PDFはリポジトリへ再配布しません。

# FP3級 10日間合格トレーナー

既存アプリを維持し、問題データと確認テストを改修しました。受検機関は日本FP協会、受検予定日は **2026年11月5日**、適用法令基準日は **2026年4月1日**です。

- 日本FP協会の2024・2025・2026年5月公表分、学科180問・実技60問を分析。
- 学科6章61単元：各5〜10問、計329問。
- 日本FP協会「資産設計提案業務」12単元：各5〜10問、計68問。旧7単元を保持し、投信・債券・外貨、不動産資料、社会保険・損保、所得税、相続税等の5単元を追加。
- 既存342問を差し替え、55問を追加。任意きんざいの旧1問を保持し、全体398問。法令確認未完了0問。
- 必須73単元は全て5問以上。任意きんざいは15単元未収録、1単元1問で不足のため未完成です。
- 各必須章のテストは25問を均等抽出。協会実技は別途、公開問題の分野構成を参考にした3択20問演習を用意。
- 公開分の同じ論点を参考にした演習259問と、範囲の補強138問を区別。年1セットの公開分を、非公開CBT全体の頻度・将来の出題確率とは表示しません。

アプリ内の「公開過去問の単元別分析・差し替え内容」で、単元ごとの観測論点、参考年度・問番号、変更の理由を確認できます。[分析レポート](docs/PAST_EXAM_ANALYSIS.md)、[収録・未収録と検証結果](docs/REPORT.md)、[機械可読の集計](docs/coverage.json)も参照してください。

## 1ファイルでコピペして使う版

`fp3-copy.html` を開くと、完全版コードを「全文コピー」または `fp3.html` として保存できます。コピーした全文をUTF-8の `fp3.html` として保存してください。ZIPの展開や追加ファイルは不要です。

- `fp3-standalone.html`：CSS・グラフ・フォント・398問を同梱した、単独で使えるHTML。
- `fp3-copy-paste.txt`：上記と完全に同じコードのテキスト版。
- `fp3-copy.html`：全文コピー・全選択・HTML保存のためのページ。学習履歴には触れません。

編集用の分離構成はそのまま維持しています。`npm run build` で通常版と単一ファイル版・コピー用ページをまとめて再生成します。以前と異なる配信元やファイルの場所へ移す場合は、元アプリからJSONバックアップを取り、新しい方で復元してください。

## 起動

配布用のCSS・Chart.js・アイコン・問題データは同梱しています。外部CDNやAPIキーは不要です。

```sh
cd /workspace/for_FP3
python3 -m http.server 8000 --bind 0.0.0.0
```

同一配信元の `index.html` または `fp3.html` を開きます。両ファイルの内容は同じです。クラウド環境では内部HTTPリクエストで起動を確認できます。

**更新時はHTMLだけでなく、data/・quiz-engine.js・assets/・webfonts/も一緒に配置してください。** file://での直接起動は環境のブラウザーポリシーで未検証のため、HTTP経由での起動を確認しています。

既存の保存キー `fp3_trainer_state` を維持しています。同じブラウザー・配信元・ポートで更新すれば既存の保存データを使用します。配信元やブラウザーを変える場合は、既存アプリのJSONバックアップを新しい方で復元してください。実際の利用者のブラウザー履歴はこの環境から参照・変更していません。

## 開発・検証

Node.js 24系（22以上）とPython 3、Chromiumを使用します。インストール時も署名・TLS・npmロックファイルの整合性検証を無効にしません。

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm test
npm run test:browser
npm run report
```

`FP3_TEST_ENTRY=fp3-standalone.html npm run test:browser` で単一ファイル版と全文コピー・HTML保存も検証できます。

ブラウザーテストは通常 `/usr/bin/chromium` を使います。異なる場所なら `CHROMIUM_PATH` を指定してください。テスト自身が専用のローカルHTTPサーバーと隔離ブラウザーを起動・終了し、実利用の履歴には触れません。file://テストだけは、この環境の管理ポリシーで遮断された場合、スキップとして明示します。

## 問題の編集と再検証

- `data/past-exam-analysis.json`：6公開資料・模範解答のURL、ハッシュ、240問の設問番号・独自要約・単元対応。原本PDFは再配布しません。
- `data/unit-revision-notes.json`：単元ごとの差替え理由。
- `data/archive/before-past-exam-revision.json`：差替前343問の監査原稿。
- `data/chapter-01.js`〜`chapter-06.js`、`chapter-09.js`：各章の問題の編集元。
- `data/legacy-questions.json`：元の7問の監査用コピー。アプリは直接使用しません。
- `data/legacy-pending.js`：置き換え前の旧問題を保存する中間データ。現在は旧q7_3だけがこの経路で出力に入り、レビューを適用して出題されます。
- `data/reviews.json`：設問・資料表・過去問リンク・版・計算メモのダイジェスト、法令基準日、検証日、状態、本文照合済み出典と抜粋・取得資料ハッシュ。
- `data/reference-policy.js`：日本FP協会公式の受検期間と法令基準日の対応。
- `data/question-bank.js`：ビルドで生成するブラウザー用データ。直接編集しません。

編集元はレビュー未適用の原稿で、最終の検証状態は生成データにあります。レビュー済み設問を変更するとダイジェスト不一致でビルドが停止します。一次資料の該当箇所と正解・解説、施行日を再照合し、reviews.jsonの当該記録を更新してから生成してください。取得成功だけで `verified` に変更してはいけません。再照合前の問題は `pending` とし、通常テストに出しません。

`scripts/review-tools.cjs` と `write-reviewed-chapter.cjs` は制作時の照合補助です。根拠本文の一時キャッシュ `/tmp/fp3-sources` を使いますが、**通常のビルド・起動・テストはキャッシュやインターネットに依存しません**。出典の再取得と読解は別途必要です。[採用した資料のURLとハッシュ](docs/source-audit.json)も参照してください。

## 保存互換性と採点

3軸ダッシュボード、学習タイマー、50時間管理、読了チェック、理解度、復習、JSON出力・復元を保持しました。問題IDと単元IDを維持し、旧成績は旧版の履歴と表示します。差替前の誤答は削除せず保留とし、同じ版の誤答だけを通常の復習へ出します。新版を解き直した際は新しい版で記録します。きんざいは標準10日計画と必須進捗集計から外し、単元・旧成績・旧復習IDは残しています。

タイマーは「開始」「再開」の時刻と、一時停止までの経過時間を保存します。Safariの休止、画面ロック、タブの終了、端末の電源オフ中も経過時間に含め、同じブラウザー・配信元で開き直すと表示を補完します。電源オフ中にプログラムを動かす必要はありません。「一時停止」中は加算せず、「終了」で分単位に四捨五入して終了日の学習時間へ一度だけ加算します。停止するまでは休止時間も含むため、休憩時には一時停止してください。保存先は従来と同じlocalStorageで、JSONバックアップにもタイマーを含みます。タイマーを含まない旧バックアップを復元した場合は停止状態になります。

問題のない単元では架空の問題を作らず、0問・不足・未検証を表示します。章別テストの成績は出題した単元ごとに記録し、章別成績も保存します。復習は誤答の抜粋なので、単元全体の理解度を上書きしません。旧成績は「旧履歴」、新成績は問題数と単元別/章別抽出を表示します。

受検予定日を確認済み期間外に変更した場合は、適用基準日を追加確認するまで通常テストを停止します。過去の履歴は削除しません。

## 出典・法改正と問題の利用

各問に参考年度・問番号と「修正・加工」「関連論点の補強」を表示します。[日本FP協会の利用条件](https://www.jafp.or.jp/exam/mohan/files/exam_riyou.pdf)に従って出典を明記しています。原問の法令基準日は2023〜2025年4月1日で、今回の2026年4月1日とは異なります。区分所有法の2026年4月施行改正、iDeCo上限等を再照合しました。年分で数値の違う税の問題は年分を明記し、2026年12月施行の値を無条件に混入させません。

各問の解説・正解・資料・過去問対応を変更したら一次資料を再確認し、reviews.jsonを更新してください。過去問の答えを機械的に付け替えたり、取得成功だけで検証済みにしたりしないでください。制作補助はscripts/past-exams/にありますが、取得本文の一時キャッシュは通常ビルドに不要です。
